# CLAUDE.md

This is a practice repo for someone learning GitHub. They are new to coding, so explain what you did in plain English, without jargon.

## How to work here

- **Always work on a new branch.** Never commit to `main`.
- **One change per pull request.** If the request covers two separate things, say so and suggest doing them one at a time.
- **When the work is done, open a pull request:**
  - Title: plain English, e.g. "Add a favourite films page".
  - Description: what changed, why, and how to check it works (what to click or open).
- **Never merge a pull request.** Amy reviews and merges everything. Your job ends when the PR is open.
- **Fixing review comments:** push more commits to the same branch so the same PR updates. Don't open a new PR.

## Safety

- **This repo is public.** Anyone on the internet can see everything in it.
- Never put passwords, API keys, tokens or any other secrets in code, config or commit messages. If you're asked to, stop and explain why not.
- Don't delete files or rewrite history unless clearly asked, and explain first what will happen.

## Explaining your work

After each change, give a short summary: which files changed, and what each change does. If you made a choice the user might not expect, point it out.
